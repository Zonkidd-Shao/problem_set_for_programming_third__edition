# 习题9-3 平面向量加法

- **分值：** 15分

## 题目描述

本题要求编写程序，计算两个二维平面向量的和向量。

## 输入格式:

输入在一行中按照“$$x_1$$ $$y_1$$ $$x_2$$ $$y_2$$”的格式给出两个二维平面向量$$v_1=(x_1, y_1)$$和$$v_2=(x_2, y_2)$$的分量。

## 输出格式:

在一行中按照`(x, y)`的格式输出和向量，坐标输出小数点后一位（注意不能输出$$-0.0$$）。

## 输入样例:
```
3.5 -2.7 -13.9 8.7
```

## 输出样例:
```
(-10.4, 6.0)
```
