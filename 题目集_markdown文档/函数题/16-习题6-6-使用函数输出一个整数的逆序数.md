# 习题6-6 使用函数输出一个整数的逆序数

- **分值：** 20分

## 题目描述

本题要求实现一个求整数的逆序数的简单函数。

## 函数接口定义
```c
int reverse( int number );
```

其中函数`reverse`须返回用户传入的整型`number`的逆序数。

## 裁判测试程序样例
```c
#include <stdio.h>

int reverse( int number );
    
int main()
{
    int n;

    scanf("%d", &n);
    printf("%d
", reverse(n));

    return 0;
}

/* 你的代码将被嵌在这里 */
```

## 输入样例
```
-12340
```

## 输出样例
```
-4321
```
