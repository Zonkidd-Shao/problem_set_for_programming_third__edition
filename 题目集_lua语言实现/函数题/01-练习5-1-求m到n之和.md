# 练习5-1 求m到n之和

- **分值：** 10分

## 题目描述

本题要求实现一个计算$$m$$ ~ $$n$$（$$m<n$$）之间所有整数的和的简单函数。

## 函数接口定义
```c
int sum( int m, int n );
```

其中`m`和`n`是用户传入的参数，保证有$$m<n$$。函数返回的是$$m$$ ~ $$n$$之间所有整数的和。

## 裁判测试程序样例
```c
#include <stdio.h>

int sum(int m, int n);

int main()
{    
    int m, n;

    scanf("%d %d", &m, &n);
    printf("sum = %d
", sum(m, n));
    
    return 0;
}

/* 你的代码将被嵌在这里 */
```

## 输入样例
```
-5 8
```

## 输出样例
```
sum = 21
```
