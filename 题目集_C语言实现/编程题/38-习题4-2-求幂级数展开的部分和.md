# 习题4-2 求幂级数展开的部分和

- **分值：** 20分

## 题目描述

已知函数$$e^x$$可以展开为幂级数$$1+x+x^2 /2! + x^3 /3! + \cdots + x^k /k! + \cdots$$。现给定一个实数$$x$$，要求利用此幂级数部分和求$$e^x$$的近似值，求和一直继续到最后一项的绝对值小于0.00001。

## 输入格式:

输入在一行中给出一个实数$$x\in [0, 5]$$。

## 输出格式:

在一行中输出满足条件的幂级数部分和，保留小数点后四位。

## 输入样例:
```
1.2
```

## 输出样例:
```
3.3201
```
